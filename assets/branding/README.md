# HCG brand assets — required

The official Hakmi Capital Group logo was **not available** when HCG Mail was created. The app
currently shows a **temporary placeholder**: the letters "HCG" in a rounded graphite tile with a thin
accent outline. It is labelled as a placeholder in its tooltip and on *Settings → About*. It is not, and
must not be presented as, the official HCG logo.

## Assets needed from HCG

| Asset | Format | Size | Used for | Drop it here |
|---|---|---|---|---|
| Logo mark (square) | PNG with transparency (SVG master welcome) | ≥ 256 × 256 px, ideally 512 × 512 | Sidebar, welcome card, About page | `src/HCG.Mail.App/Assets/Branding/hcg-logo.png` |
| Logo mark, light-background variant (optional) | PNG | as above | HCG Classic skin | `src/HCG.Mail.App/Assets/Branding/hcg-logo-light.png` (needs a small code change to select per skin) |
| Application icon | Windows `.ico` containing 16, 24, 32, 48, 64, 128, 256 px | — | Taskbar, Start menu, title bar, `HCGMail.exe` | replace `src/HCG.Mail.App/Assets/Icons/hcg-mail-placeholder.ico` and update `ApplicationIcon` in `HCG.Mail.App.csproj` / `Icon=` in the window XAML |
| macOS icon (later) | `.icns` | 1024 px master | `.app` bundle | — |
| Metallic wordmark (optional) | SVG/PNG | — | could replace the typographic "HCG MAIL" wordmark | — |

## How the asset system works

* `Views/BrandMark.axaml(.cs)` checks for `avares://HCGMail/Assets/Branding/hcg-logo.png` at start-up.
  If the file exists (it is embedded automatically via `<AvaloniaResource Include="Assets\**" />`),
  the official logo is shown and the placeholder is hidden. No other change is needed.
* The "HCG MAIL" wordmark is live text with a brushed-metal gradient (`Hcg.Brush.Metal` in
  `Themes/Palette.axaml`); the skin controls its colours.

## Placeholder files in this repository

* `src/HCG.Mail.App/Assets/Icons/hcg-mail-placeholder.ico|png` — copies used by the app build.
